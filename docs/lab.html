Ranking de hipótesis

Cada hipótesis se juzga por sus predicciones. Cobertura = credibilidad de las estructuras que confirman alguna predicción / credibilidad de todas las estructuras. Refutación = credibilidad de lo que contradice cada predicción. Ajuste = cobertura − refutación. Lo único que se ingresa a mano es la confianza de base en cada fuente.

Fuentes

La confianza de base es el ancla del cálculo y se puede discutir como cualquier otra cosa. Las copias cuentan como una sola fuente independiente.
